Arquitetura do Protótipo

Resumo da estrutura técnica atual de comunicação entre a interface web, API backend e o motor de IA.

Fluxo de Dados

  • Interface Frontend: Aplicação web estática em HTML/CSS/JS simples.
  • Backend (Render): Servidor Node.js intermediário para proteção das chaves de API.
  • Motor de IA: Integração direta com a API do Gemini via requisições REST.

Entregáveis da Fase Protótipo

  • Validação de viabilidade para apoio operacional rápido do time.
  • Sem necessidade de banco de dados complexo nesta fase de testes.
  • Publicação em ambiente cloud acessível de qualquer dispositivo.

Evolução do Projeto

Planejamento para transição do protótipo web para a solução corporativa definitiva em Microsoft Copilot Studio.

Integração Corporativa Futura

  • Autenticação única usando as credenciais da empresa (Entra ID).
  • Disponibilização do assistente diretamente no Microsoft Teams.
  • Conectores nativos com a base de conhecimento no SharePoint do setor.

Requisitos Técnicos de Liberação

  • Aprovação de políticas de DLP e segurança da informação.
  • Atribuição das licenças apropriadas na tenant da empresa.
